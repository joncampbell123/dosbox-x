2026.10.01
- Fixed DOS FCB operations trying to read/write from device_CON when performed
    on an unopened or non-existent file. (cimarronm)
  - Don't prompt for working directory when -conf or -userconf is used
    (maron2000)
  - Added RPC debugger agent interface (freeng)
  - Fix OpenGL scaling when modeswitch is off (jpernst)
  - Modesetting resolution change exclusive to fullscreen. (DieSkarrj)
  - Added MCP Protocol support (caiiiycuk)
  - Fixed parsing of command-line executable arguments (maron2000)
  - Enable PS2 mouse events (cyberfox)
  - Fixed VHD fixed-disk geometry detection to correctly decode the partition
    start cylinder from the MBR CHS fields (the high bits were not shifted),
    reject malformed CHS/LBA partition entries instead of producing a bad or
    out-of-bounds sector address. (cimarronm)
  - Added /V arg for `VER` command to just report the version (bushtail)
  - drive_virtual: fixed CHDIR succeeding on a file on drive Z:
    (MaxFreedomPollard)
  - Fixed the LOCK (0xF0) prefix in the normal, full, and dynamic (dyn_x86 and
    dynrec) CPU cores to prefix the following instruction instead of
    executing as its own no-op, and raise a #UD exception on 80186+ if it
    precedes an instruction LOCK is not legal on. (cimarronm)
  - Fixed IDE CHS cylinder carry handling (caiiiycuk）
  - Fixed Voodoo OpenGL texture cache invalidation (caiiiycuk）
  - Fixed PIT timer emulation: prevented float-to-unsigned saturation on ARM
    architectures when Mode 0/4 counts past terminal count, fixed gate pause
    delay calculation for Mode 0/4, and unified Mode 2/3 gate trigger handling
    per 8253/8254 specification. (cimarronm)
  - Experimental: Added Pre-compiled .deb package for Ubuntu 22.04/24.04/26.04
    (maron2000)
  - Experimental: Added support for AppImage on x64 Linux (maron2000)
  - Fixed PIT timer emulation BCD write handling to keep packed BCD values
    intact across two-byte counter writes before converting to binary. (cimarronm)
  - Enable PS1 audio (cyberfox1)
  - Debugger: Added optional filename arguments to MEMDUMP and MEMDUMPBIN,
    defaulting to MEMDUMP.TXT and MEMDUMP.BIN. (cimarronm)
  - Fixed initial directories for GLSL and language file selection dialogs
    (maron2000)
  - ethnet: Initialize SDLNet before initializing ethnet support (patcade)
  - Fixed redefinition of enums to enable building on Macports for legacy macOS
    (maron2000)
  - Fixed build error of MinGW 64-bit builds due to MSYS2 are gradually
    dropping MinGW updates and migrate to UCRT64. (maron2000)
  - Added Pro Audio Spectrum, Pro Audio Spectrum Plus and Pro Audio Spectrum 16
    support (firevaran)
  - Added Crystal CS4231 codec, along with a Windows Sound System (WSS) support
    (cyberfox1)
  - Added Pentium Pro x87 FCMOVcc, FCOMI/FCOMIP, and FUCOMI/FUCOMIP support
    to the dyn_x86 and dynrec CPU cores, and fixed FCOMI/FUCOMI to clear AF,
    SF, and OF. (cimarronm)
  - Added Gravis Ultrasound Max support to the existing GUS implementation,
    building on the CS4231 codec (cyberfox1)
  - FPU: Restored x87 stack metadata if a push-and-load instruction faults on
    its memory operand. (cimarronm)
  - FPU: FSTENV/FNSTENV now masks all floating-point exceptions after saving the
    environment. (cimarronm)
  - Linux: Fixed garbled characters in image file open dialog (maron2000)
  - Enabled PS/2 mouse on BIOS C200 call (cyberfox1)
  - PC-98: keep the bus mouse interrupt running across save states (gymzatan)
  - Configuration tool: Fixed a crash when selecting the Devices section.
    (cimarronm)
  - Added 3D Acceleration for S3 ViRGE (LeonG-ZA)
  - Increased PAS/OPL volume to match DBX gain (cyberfox1)
  - FPU: Refactored the implementation and fixed x87 status-word
    condition-code reporting and tag words saved with FPU state. (cimarronm)
  - CoreMIDI: Fixed device name matching for names starting with digits.
    (maron2000)
  - Added Sound Blaster AWE32 support for games that use EMU8K (cyberfox1)
  - Various fixes and improvements to the original 86box derived emu8k
    implementation. (cyberfox1)
  - FPU: Unified the non-long-double, long-double, and x86 host FPU engines
    around shared 80-bit conversion and stack-loading paths. Improved accuracy
    against real x87 hardware on both x86 and non-x86 hosts. (cimarronm)
  - FPU: Unified real, integer, packed-BCD, and register store operations
    across FPU engines. Fixed x87 stack handling and incorrect integer-store
    results. (cimarronm)
  - Dynamic core: By default, pass all FPU/MMX opcodes to normal core so that
    the FPU exception handling necessary for Windows 95 to task switch the
    CPU and FPU state can work properly. In the event that this makes your
    DOS games slower, there is a dosbox.conf option to re-enable FPU/MMX
    handling by dynamic core for DOS games that do not multitask. (joncampbell123)
  - Fixed items in Configuration Tools window were cropped (maron2000)
  - Added configuration and switch for composite mode (gschmidl)
